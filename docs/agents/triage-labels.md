# Triage labels

Use this table to convert each skill role to its issue label.

| Skill role | Issue label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue. |
| `needs-info` | `needs-info` | More information is necessary from the reporter. |
| `ready-for-agent` | `ready-for-agent` | The specification is complete. An agent can do the work. |
| `ready-for-human` | `ready-for-human` | A person must do the work. |
| `wontfix` | `wontfix` | The issue will not be implemented. |

When a skill requests a role, use the issue label in this table. To change the labels, edit the Issue label column.
